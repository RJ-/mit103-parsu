# Week 16 — Data Entry Procedures and Effective Coding

**Program outcomes:** `a.2` · `a.3`  
**Portfolio thread:** System Interface Design

## Learning outcomes

By the end of this week you should be able to:

- Explain the uses of effective coding to support users in accomplishing their tasks.
- Design effective and efficient data capture approaches for people and systems.
- Recognize the role of proper coding and capture methods in improving system usability and efficiency.

## Instructional content

- Introduction to data entry procedures
- Effective coding for user tasks
- Principles of efficient data capture
- Data capture approaches for people and systems

## In class

- **Lecture-discussion (30 min).** Classification, sequence, block and mnemonic codes; the cost of a bad coding scheme over a system's lifetime.
- **Analysis of data entry forms and coding schemes (50 min).** Examine real institutional codes — student numbers, item codes, account numbers. Which ones encode meaning that later became false?
- **Guided discussion (30 min).** Human capture versus automated capture: barcodes, OCR, sensors, integrations.

## Lab and independent work

- Define the complete coding scheme for your system and document it in the data dictionary.
- Specify data capture methods per entity, with justification.

## Assessment

Initial System Interface Design output; recitation and rubric-based assessment.

## Check yourself

- Does your code embed a fact that could change — a department, a region, a year?
- What is the re-keying cost per record in your current process, and what does your design remove?
