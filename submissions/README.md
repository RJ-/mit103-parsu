# Submissions

Create a folder here named after your surname, then a subfolder per deliverable:

```
submissions/
  briones/
    01-proposal/
    02-prototype/
    03-system-design/
```

See [How to submit](../CONTRIBUTING.md) for the branch and pull-request workflow.

Anonymise personal data before committing. See [Licensing and data privacy](../LICENSING.md).
