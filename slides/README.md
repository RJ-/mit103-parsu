# Slides

Lecture decks are posted here as they are delivered, named `week-NN-topic.pdf`.

**Third-party decks are linked, not stored.** Several sources in the
[resource list](../resources.md) offer instructor slides — Regnell's
*Requirements Engineering* repository, Valente's *Software Engineering: A Modern
Approach* (900+ slides, on request), and OpenStax — but the FREE-badged ones may
not be re-hosted. Links live on the relevant week page.
