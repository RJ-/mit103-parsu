# Week 12 — Input Design: Functional and Engaging Input Displays

**Program outcomes:** `a.4` · `h.2`  
**Portfolio thread:** System Physical Design

## Learning outcomes

By the end of this week you should be able to:

- Design functional input forms for users of business systems.
- Design engaging input displays for users of information systems.
- Apply the principles of effective input design in business and organizational settings.

## Instructional content

- Introduction to input design
- Principles of effective input design
- Designing functional input forms for business systems
- Designing engaging input displays for information systems

## In class

- **Lecture-discussion (30 min).** Input design principles: minimise keystrokes, minimise error, minimise cognitive load.
- **Input form analysis (50 min).** Students bring a real government or institutional form. The class identifies every place it forces the user to know something the system already knows.
- **Guided discussion (30 min).** One-question-per-page versus dense forms: when does each win?

## Lab and independent work

- Redesign one real input form from your organisation. Submit before/after with annotated justification against GOV.UK or USWDS patterns.
- Build the primary data entry screen for your own system.

## Assessment

Initial System Physical Design output; recitation and rubric-based assessment.

## Check yourself

- How many fields on your form could be derived rather than asked?
- What happens to a user who gets three fields wrong at once?
