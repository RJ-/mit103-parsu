# Week 15 — Types of User Interfaces and Onscreen Dialog

**Program outcomes:** `h.2` · `f.2`  
**Portfolio thread:** System Interface Design — submission

## Learning outcomes

By the end of this week you should be able to:

- Design a variety of user interfaces appropriate to user needs and system requirements.
- Design effective onscreen dialog for human-computer interaction.
- Apply HCI principles in developing clear, accessible and user-friendly interfaces.

## Instructional content

- Types of user interfaces
- Designing user interfaces for different environments
- Designing effective onscreen dialog
- Applying HCI principles in interface development

## In class

- **Lecture-discussion (25 min).** Interface types and the environments that select them.
- **Heuristic evaluation (60 min).** Each student evaluates two classmates' prototypes against all ten heuristics, rating severity 0–4. This is the graded peer-critique activity.
- **Onscreen dialog clinic (35 min).** Rewrite the error, confirmation and empty-state messages in three prototypes. Messages must say what happened and what to do next.

## Lab and independent work

- Act on the heuristic evaluation findings; document every change and the finding that prompted it.
- Submit the **System Interface Design** package as a pull request.

## Assessment

System Physical Design submission, rubric-assessed (Laboratory/Performance, 40%). Heuristic evaluation contributes to Class Standing.

## Check yourself

- Which severity-3 or severity-4 finding did you choose not to fix, and what is your justification?
- Do your button labels and your success messages use the same verb?
