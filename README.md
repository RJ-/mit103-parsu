## Course description

This course focuses on the analysis, modeling, design, and implementation of
complex information systems in organizational settings. It covers requirements
engineering, enterprise process analysis, architectural design, systems modeling,
prototyping, implementation planning, integration strategies, deployment, and
post-implementation evaluation. Emphasis is placed on applying structured and
agile approaches, quality criteria, usability considerations, and systems
thinking in the development of scalable and context-responsive IT solutions.

## Course outcomes

At the end of the course you should be able to:

1. Analyze complex organizational processes and derive defensible system requirements.
2. Develop architectural, process, and data models that support robust information system design.
3. Design and implement scalable, user-centered, and maintainable information systems solutions.
4. Evaluate system alternatives and implementation strategies using quality and feasibility criteria.
5. Collaborate with stakeholders in planning, validating, and refining system solutions.

## How this repository works

Everything here is plain Markdown under version control. That is deliberate — it
is the same collaborative tooling the course assesses under program outcome
**f.2** (_utilize collaborative development tools effectively_), and the
repository you build over the semester is a portfolio artefact under **e.3**.

You do not need Git to read this site. You do need it to submit.

```
weeks/          one page per instructional week
deliverables/   what to submit, when, and the rubric it is marked against
  rubrics/
templates/      fill-in-the-blank instruments and outlines
resources.md    40 open and free resources, badged by licence
submissions/    your work goes here, in a folder named after you
slides/         lecture decks
```
